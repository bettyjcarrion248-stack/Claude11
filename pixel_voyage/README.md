# 像素旅途 · PIXEL VOYAGE

一段 24 秒、1080p 的像素风动画短片。**画面里每一个像素、配乐里每一个音符，都是代码现算出来的**，没有用任何图片素材、音频素材或 AI 绘图/视频模型。

成片：`out/pixel_voyage.mp4`

## 剧情

| 时间 | 画面 |
|---|---|
| 0–3s | 夜空标题画面："像素旅途"逐字弹跳落下，英文打字机效果，PRESS START 闪烁 |
| 3–17s | 抖动转场进入清晨。小白团子提着灯笼向右走，镜头视差滚动，太阳东升西落，飞鸟掠过，经过冒炊烟的小屋 |
| 14–19s | 黄昏到入夜：天空变色、星星浮现、月亮升起，路灯和窗户依次点亮，灯笼亮起 |
| 17–21s | 主角走到篝火旁慢慢停下，萤火虫飞舞，一颗流星划过 |
| 21–24s | 片尾 THE END，渐隐结束 |

## 这类"AI 做的视频"是怎么生成的

流程很简单：**让 AI 写一个程序，由程序把视频"算"出来**。

```
文字需求 ──► AI 写代码 ──► 程序逐帧绘制像素 ──► FFmpeg 编码 ──► MP4
                       └─► 程序合成 8-bit 音乐 ──┘
```

`pixel_voyage.py`（画面）的几个关键技巧：

1. **在小画布上作画**：只画 320×180，最后用最近邻插值放大 6 倍到 1920×1080，像素颗粒感就是这么来的。
2. **画面只是时间的函数**：`render(t)` 输入一个时间，返回一帧。镜头位置、太阳角度、调色板、火焰形状都由 `t` 算出，所以 720 帧可以多进程并行渲染。
3. **Bayer 有序抖动**：天空渐变、光晕、转场、淡入都不用半透明，而是按 4×4 / 8×8 的抖动矩阵决定每个像素用哪种颜色，这是老游戏机的经典做法。
4. **视差滚动**：远山、近山、地面以 0.08 / 0.18 / 0.45 / 1.0 倍速移动，看起来就有纵深。
5. **程序化地形**：山脉是几条正弦波叠加出来的高度线，松树、草丛、花朵、石头的位置用确定性哈希生成，所以世界可以无限延伸，每一帧都能重现。
6. **昼夜循环**：为黎明、白天、日落、黄昏、夜晚各配一套调色板，按时间插值。
7. **精灵角色**：主角是用字符画手写的 14×15 像素图，每个字母对应一种颜色，走路有 4 帧动画，还会眨眼。
8. **像素字体**：英文是自己定义的 5×7 点阵字体，中文用 GNU Unifont 16×16 点阵字体，关掉抗锯齿渲染。

`chiptune.py`（音乐）的做法：

- 只用三种波形：方波（主旋律、琶音）、三角波（贝斯）、噪声（鼓），和 FC 红白机的声音芯片一样。
- 和弦进行 C – G – Am – F，120 BPM，主旋律加上延迟回声。
- 跟画面共用同一条时间轴：标题落下有"咚"声，打字有"嘀"声，按 START 有投币音，入夜后鼓点变稀，流星划过有"叮铃"声，篝火有噼啪声。

## 运行

依赖：Python 3、NumPy、Pillow、FFmpeg，以及 Unifont 字体（`apt install fonts-unifont`）。

```bash
python3 pixel_voyage.py                       # 渲染完整视频，4 核大约 30 秒
python3 pixel_voyage.py --stills 1.5 8 19.5   # 只导出这几个时刻的静帧，调试用
```

## 想改成自己的版本

- 改标题、副标题：`pixel_voyage.py` 顶部的 `TITLE_CN` / `TITLE_EN` / `SUBTITLE`
- 改角色外观：编辑 `BODY` 字符画和 `CHAR_PAL` 调色板
- 改配色：编辑 `THEMES`（每个时段一套颜色）
- 改音乐：编辑 `chiptune.py` 里的 `CHORDS` 与 `MELODY`（MIDI 音高，60 = 中央 C）
- 改长度、节奏：调整顶部"时间轴"区块里的常量
